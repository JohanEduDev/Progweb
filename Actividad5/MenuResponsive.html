Responsive Web Desing o tambien conocido como Diseño web Adaptable, es una tecnica de diseño y desarrollo web que mediante el uso de estructura flexibles (contenedores flexible, imagenes y video flexibles) y junto con Media Qeries especificados en css, lograna adaptar un sitio web al entorno de dispositivo del que se encuentre. Con ésta tecnica se consigue que el contenido del diseño se vea bien y pueda ser bastante legible para los usuarios sobre el dispositivo con el que éste interactúe.
